VOCAL MATCH - analyzer (command-line), macOS and Linux

This package installs the `vocalmatch` command: it analyses the lead vocal of a
reference and writes a preset (EQ, compressor, saturation, de-esser, delay, reverb,
doubler/width) for your own vocal, and can
render your dry vocal through it. On a Mac, download VocalMatch-macOS-Universal instead:
it holds the AU / VST3 plug-in and this analyzer, installed together by install-mac.sh.

NEEDS
  Python 3.10 or newer (macOS's built-in python3 is 3.9, too old). If the installer
  says none was found: install Python from https://www.python.org/downloads/ or run
  "brew install python@3.12", then run the installer again.
  Internet access during install (numpy, scipy and friends come from PyPI).

INSTALL
  1. Open Terminal (Applications > Utilities > Terminal).
  2. Type "bash " (with a space), drag install.sh from this folder into the
     Terminal window, and press Return.
  3. Answer Y if it offers to add ~/.local/bin to your PATH.
  4. Wait for "Vocal Match analyzer is installed and passed its self-test."
  5. Open a new Terminal window so the PATH change takes effect.

  It installs into a private environment (macOS: ~/Library/Application Support/
  VocalMatch, Linux: ~/.local/share/vocalmatch) and links ~/.local/bin/vocalmatch.
  Nothing is installed system-wide and no password is asked for.

USE
  vocalmatch analyze --reference reference_vocal.wav --dry my_vocal.wav \
                     --out preset.json --render matched.wav

  --reference can be the full song if Demucs is installed (bash install.sh
  --with-separation, about 1 GB more); otherwise give an isolated vocal stem (an a
  cappella). WAV, FLAC and MP3 are read. Analysis takes one to a few minutes.
  preset.json is plain text: every setting is in real units (Hz, dB, ms) and can be
  edited, then re-rendered:

  vocalmatch render --preset preset.json --dry my_vocal.wav --out out.wav
  vocalmatch selftest          checks the installation (about a minute)
  vocalmatch --help            all commands

UPDATE
  Download the newer package and run its install.sh: it replaces the old copy.

UNINSTALL
  bash uninstall.sh            (add --purge to also delete the logs)
